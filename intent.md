## Core Objective

To build a premium, personal portfolio for Kamiye. The site serves as a digital identity to showcase professional experience in Machine Learning, Generative AI, and product strategy, alongside selected technical projects and social links.

## Design Philosophy: Quiet Luxury & Editorial

This site must actively subvert standard "developer portfolio" tropes. It should feel like a digital lookbook for a high-end fashion house, drawing architectural inspiration from editorial campaigns of luxury brands like Loro Piana, Hermès, and Ralph Lauren.

* **Aesthetic Rules:** No bento boxes, no glowing neon, no terminal-themed UI, and no dark mode.
* **Space & Structure:** Massive amounts of negative space, full-bleed imagery, asymmetrical editorial layouts, and a strict adherence to a warm, minimalist color palette.
* **Typography as Art:** Heavy reliance on elegant, high-contrast serif typography for headings, paired with ultra-clean, legible sans-serif for technical body copy.

## The "Framer Feel" (Interaction Design)

The site is built in code but must feel like a polished Framer template. The interactions should feel expensive, physical, and fluid.

* **Fluid Scrolling:** The native browser scroll must be overridden with butter-smooth, eased scrolling (e.g., using Lenis).
* **Physics-Based Motion:** All hover states, page transitions, and micro-interactions must use spring physics rather than linear CSS transitions.
* **Scroll Choreography:** Elements should react subtly to the scroll position (e.g., gentle parallax on project images, typographic reveals, elements gliding into the viewport).

## Content Architecture

The site will be streamlined and focused, presenting technical work with the reverence of an art gallery.

* **Hero:** A bold, typography-driven introduction defining the value proposition (Data Science & Generative AI).
* **The Archive (Projects):** Selected case studies presented as vertical, lookbook-style imagery rather than traditional tech cards.
* **Concierge (Footer):** A massive, solid block of deep color (terracotta/warm red) acting as the contact and social hub, mirroring a luxury brand's service footer.
